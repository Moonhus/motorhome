# Commercial Motorhomes

Listing site for **Commercial Portfolio Pty Ltd**, a second-hand motorhome yard in Brisbane, Queensland.

## Local development

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

| Command | Purpose |
| --- | --- |
| `npm run dev` | Development server on port 3000 |
| `npm run build` | Production build |
| `npm run lint` | ESLint |
| `npm test` | Inventory filter tests |

Inventory data lives in `src/data/motorhomes.ts`. Listing photos are in `public/images/`.
